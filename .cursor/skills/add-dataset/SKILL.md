# Add a MillionTrees Dataset

## Step 1 — Determine geometry type

Ask the user (or infer) whether annotations are:
- **Points** → `[TreePoints]` section
- **Boxes** (bounding rectangles) → `[TreeBoxes]` section
- **Polygons** (crown outlines) → `[TreePolygons]` section

This controls the `annotation_csvs.cfg` section and the CSV filename prefix.

## Step 2 — Write the data_prep script

Create `data_prep/<DatasetName>.py` following the pattern of existing scripts (e.g. `Ventura2022.py`, `process_ofo_field.py`).

**Required output schema** (`docs/contributing.md`):
```
image_path     — absolute path to the image on disk
source         — citation string, e.g. "Smith et al. 2023"
geometry       — WKT in *image* pixel coords (0,0 = top-left). NOT geographic CRS.
existing_split — (optional) "train" or "test"
```

**Key rules:**
- `image_path` must be a **full absolute path** — never a basename.
- Use `deepforest.utilities.read_file()` to convert geographic shapefiles/GeoDataFrames → pixel coords. Pass `root_dir=` pointing to the directory with the .tif.
- Strip all metadata columns (species, DBH, etc.) — only the schema columns above.
- Save the CSV next to the images: `<data_root>/annotations.csv`.

**Tiling large .tif orthomosaics** (images wider/taller than ~2000 px):
```python
from deepforest.preprocess import split_raster
from deepforest.utilities import read_file
import os

gdf = read_file(annotations_df, root_dir=img_dir)
tiles = split_raster(
    gdf,
    path_to_raster=tif_path,
    root_dir=img_dir,
    save_dir=images_dir,
    patch_size=800,
    patch_overlap=0,
    allow_empty=False,
)
tiles = tiles.rename(columns={"image_path": "filename"})
tiles["image_path"] = tiles["filename"].apply(lambda f: os.path.join(images_dir, f))
tiles["source"] = "Author et al. YEAR"
tiles.to_csv(os.path.join(output_dir, "annotations.csv"), index=False)
```

## Step 3 — Write a verification overlay image

Save at least one overlay PNG **in the same directory as the images** so alignment can be confirmed visually:

```python
import numpy as np
from PIL import Image
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
import matplotlib.patches as patches
import pandas as pd, os, shapely.wkt

def write_overlay(csv_path: str, images_dir: str, max_samples: int = 4):
    df = pd.read_csv(csv_path)
    for img_path in sorted(df["image_path"].unique())[:max_samples]:
        sub = df[df["image_path"] == img_path]
        img = np.array(Image.open(img_path).convert("RGB"))
        fig, ax = plt.subplots(figsize=(8, 8))
        ax.imshow(img)
        for _, row in sub.iterrows():
            geom = shapely.wkt.loads(row["geometry"])
            gt = geom.geom_type
            if gt == "Point":
                ax.plot(geom.x, geom.y, "c+", markersize=10, markeredgewidth=2)
            elif gt == "Polygon":
                xs, ys = geom.exterior.xy
                ax.plot(xs, ys, "c-", linewidth=1.5)
            else:
                b = geom.bounds
                rect = patches.Rectangle(
                    (b[0], b[1]), b[2]-b[0], b[3]-b[1],
                    linewidth=1.5, edgecolor="cyan", facecolor="none"
                )
                ax.add_patch(rect)
        ax.set_title(f"{os.path.basename(img_path)} — {len(sub)} annotations")
        ax.axis("off")
        out = os.path.join(images_dir,
              "overlay_" + os.path.splitext(os.path.basename(img_path))[0] + ".png")
        fig.savefig(out, dpi=120, bbox_inches="tight")
        plt.close(fig)
        print(f"Overlay saved: {out}")
```

## Step 4 — Add the CSV to `annotation_csvs.cfg`

Add the **full absolute path** in the correct section of `data_prep/annotation_csvs.cfg`:

```ini
[TreePoints]   # or TreeBoxes / TreePolygons
...
/orange/ewhite/DeepForest/<Dataset>/annotations.csv
```

## Step 5 — Add documentation in `docs/datasets.md`

Add a subsection under the appropriate geometry heading (`# Points`, `# Boxes`, `# Polygons`):

```markdown
## <Author(s)> <Year>

### Source Name: "<source string matching annotations>"

![sample_image](public/<SourceName>.png)

**Citation:** <full citation>

**Location:** <geographic region>

<1-2 sentences: tree type, annotation method, sensor.>
```

The `public/<SourceName>.png` is auto-generated by `create_mini_datasets()` during packaging.

## Step 6 — Check version alignment

```bash
grep "version\s*=" data_prep/package_datasets.py
```

Compare against the latest key in `_versions_dict` in:
- `src/milliontrees/datasets/TreePoints.py`
- `src/milliontrees/datasets/TreeBoxes.py`
- `src/milliontrees/datasets/TreePolygons.py`

If `package_datasets.py` has a newer version (e.g. `v0.14`) that is not yet in `_versions_dict`, flag to the user — the URL entry must be added **after** the package is uploaded.

## Step 7 — Run packaging

```bash
cd /blue/ewhite/b.weinstein/src/MillionTrees
uv run python data_prep/package_datasets.py
```

For long jobs on HiPerGator, model a new submit script on `slurm/submit_ofo_field.sh` and submit with `sbatch`.

After completion verify:
- New source appears in `Tree{Points,Boxes,Polygons}_<version>/random.csv`
- `docs/public/<SourceName>.png` was generated
- Images are present in `Tree{Points,Boxes,Polygons}_<version>/images/`

## Step 8 — Update download URLs (after upload)

Once the zip is uploaded to `https://data.rc.ufl.edu/pub/ewhite/MillionTrees/`, add a version entry to all three dataset files:

```python
"0.14": {
    "download_url": "https://data.rc.ufl.edu/pub/ewhite/MillionTrees/TreePoints_v0.14.zip",
    "supervised_download_url": "https://data.rc.ufl.edu/pub/ewhite/MillionTrees/TreePoints_supervised_v0.14.zip",
    "compressed_size": <bytes>,   # stat --printf="%s\n" TreePoints_v0.14.zip
}
```
